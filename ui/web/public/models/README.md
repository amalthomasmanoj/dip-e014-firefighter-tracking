# Firefighter model

`professional-firefighter.glb` is a real-world-scale firefighter in tan turnout
gear with reflective bands and a helmet.

- Source: [Innerscene 3D Parts Library](https://www.innerscene.com/tools/library/3d-parts/firefighter-standing-3d-person-emergency-services-3c007c1f)
- Original asset: Innerscene, adapted from MakeHuman CC0 assets
- License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- SHA-256: `401031ea91a9f831f786e2984ac06aa666f2af4ab748187c3c90b1803d23dcf3`

The model is static. The tracking UI applies position, waist-IMU heading, and
the detected lying posture to the complete model at runtime.
